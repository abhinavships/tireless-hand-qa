[   0.0s  intro card (frozen to fit)]
This is Tireless Hand, our testing system for the FlytBase drone cockpit, Level 1. It opens the real cockpit at phone, tablet and desktop sizes, and checks that what the operator sees matches the true state from the server. To prove the tests work, we planted bugs on purpose: fifteen of sixteen were caught. We also found three real bugs: stale data shown as live, no separation between organisations, and unsafe drone names.

[   2.5s  L1_S01_shell-contract (49.0s video)]
The cockpit shell: every key part of the screen must be visible and usable. Both planted bugs, a missing video tile and a missing control panel link, are caught.

[  51.5s  L1_S02_live-fleet (22.0s video)]
The drone list must match the real fleet, live. A planted bug that hides a drone is caught.

[  73.6s  L1_S03_selected-telemetry (64.8s video)]
The telemetry panel must show the selected drone's real numbers. Planted battery bugs are caught.

[ 138.4s  L1_S04_flight-workflow (50.9s video)]

[ 189.3s  L1_S05_offline-truth (57.3s video)]

[ 246.6s  L1_S06_socket-recovery (25.8s video)]

[ 307.4s  L1_S08_responsive (17.9s video)]
